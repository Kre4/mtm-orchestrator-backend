# Завершение задачи в MTM

Когда дело выполнено, свою задачу можно отметить завершённой через чат. Например: «Отметь задачу “Отправить отчёт” выполненной».

Завершение одной однозначно найденной задачи относится к разрешённым действиям и не требует отдельного подтверждения. Если подходящих задач несколько, помощник сначала уточняет, какую именно нужно завершить.

Массовое завершение требует подтверждения пользователя.

В актуальном интерфейсе выполненные задачи находятся в **Журнале** внутри [Архива](10_archive.md). Завершение не равно удалению: для удаления действует отдельное обязательное подтверждение.
