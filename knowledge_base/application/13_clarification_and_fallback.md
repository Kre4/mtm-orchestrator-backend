# Уточнения, fallback и ручная проверка

Если запрос нельзя надёжно обработать сразу, MTM не должен угадывать недостающие данные.

Помощник задаёт уточняющий вопрос, когда не хватает обязательного параметра, найдено несколько подходящих объектов, дата или время неоднозначны либо смысл запроса остаётся неясным. Уточнение должно быть коротким и относиться только к недостающей информации.

Для одного сценария предусмотрено не более **двух последовательных целевых уточнений**. Если после этого запрос всё ещё нельзя разрешить, система выбирает безопасный следующий шаг: при низком риске — fallback, а в существенном неоднозначном случае возможна ручная проверка.

Для справочного запроса без надёжного источника применяется fallback: помощник сообщает, что не нашёл достаточно надёжной информации. Отсутствие источника само по себе не создаёт заявку на ручную проверку.

Подтверждение удаления — отдельный механизм: уточнение помогает понять запрос, а подтверждение разрешает конкретное рискованное действие.
