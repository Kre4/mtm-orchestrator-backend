# Контексты: организация действий по условиям

**Контекст в GTD** — условия, необходимые для действия: место, инструмент или доступ к человеку. По контекстам можно организовать списки следующих действий, чтобы видеть подходящие дела в нужной ситуации.

Например, список «За компьютером» может содержать «выгрузить таблицу», а список вопросов к руководителю — «согласовать тему доклада». Это группировка по условиям выполнения, а не по важности или проекту. Действия одного проекта могут требовать разных условий.

Если нужного инструмента или человека нет, действие сейчас недоступно. После отбора по контексту остаётся выбрать среди доступных вариантов с учётом времени, энергии и приоритета — это задача [Engage](12_engage_and_priorities.md).
