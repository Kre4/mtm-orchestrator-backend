# Просмотр и поиск своих задач в MTM

В MTM можно просматривать и искать только свои личные задачи.

Через чат можно написать, например:
- «Покажи мои задачи»;
- «Что у меня на завтра?»;
- «Покажи расписание на сегодня»;
- «Найди задачу про отчёт».

Такие запросы прямо предусмотрены политикой просмотра и поиска задач.

Если запросу соответствуют несколько задач и без уточнения нельзя понять, какую из них имеет в виду пользователь, помощник должен уточнить выбор.

Задачи с указанной датой отображаются в [Календаре](07_task_dates_and_calendar.md), а задачи без даты — в [«Когда-нибудь»](09_someday.md).

Доступ к задачам другого пользователя не предоставляется.
