# «Когда-нибудь» в MTM: задачи без даты

В раздел **«Когда-нибудь»** в MTM попадают задачи без даты. Если у задачи появляется дата, она относится к [Календарю](07_task_dates_and_calendar.md).

Это правило размещения в интерфейсе MTM. Оно не означает, что пользователь отказался от задачи или считает её необязательной.

Не путайте раздел MTM с GTD **Someday/Maybe**. В методологии Someday/Maybe — это возможные дела без текущего обязательства; в MTM «Когда-нибудь» используется для задач без даты.
