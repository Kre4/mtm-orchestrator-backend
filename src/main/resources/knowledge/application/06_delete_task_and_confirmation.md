# Удаление задачи и подтверждение

Задачу можно удалить через чат, но удаление не выполняется сразу. Перед этим помощник должен запросить явное подтверждение пользователя.

Подтверждение должно быть конкретным: система сообщает, какое действие произойдёт и какой объект будет затронут. Если пользователь не подтвердил удаление, задача не удаляется.

Просьба вроде «удаляй без подтверждения» не отменяет это правило. Массовое удаление также требует подтверждения; при массовом действии пользователю должно быть понятно, сколько объектов будет затронуто.

Удалённые задачи относятся к **Корзине** внутри [Архива](10_archive.md). Если дело выполнено, а не должно быть удалено, используйте [завершение задачи](05_complete_task.md).
