# Создание задачи в MTM

Новую личную задачу можно создать через AI-чат обычной фразой. Например: «Добавь задачу “Отправить отчёт” на 15 октября».

Создание одной задачи относится к разрешённым действиям и не требует отдельного подтверждения, если запрос понятен и содержит необходимые данные.

По текущей политике при создании система должна понимать название задачи и ситуацию с датой. Если дата указана неоднозначно или непонятно, есть ли она вообще, помощник задаёт короткий уточняющий вопрос вместо того, чтобы додумывать значение.

Если пользователь явно сообщает, что даты нет, задача создаётся без даты. По актуальному решению второго этапа такие задачи относятся к разделу [«Когда-нибудь»](09_someday.md). Задачи с датой отображаются в [Календаре](07_task_dates_and_calendar.md).
