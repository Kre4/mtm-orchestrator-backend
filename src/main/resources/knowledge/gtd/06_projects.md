# Проекты в GTD: результат и следующие действия

**Проект в GTD** — результат, для которого нужно больше одного действия. Размер сам по себе не решает, является ли дело проектом: важна необходимость нескольких шагов.

Например, «заявление принято университетом» — результат проекта. «Скачать форму заявления» — одно из действий. Формулируйте результат так, чтобы можно было проверить его достижение: скачанная форма ещё не означает, что заявление принято.

Список проектов помогает отслеживать незавершённые результаты. Связанные действия определяют через вопрос: «Какой результат продвинет этот шаг?» Подготовительные действия могут идти последовательно: заполнить форму получится после её получения.

При обзоре проекта проверяйте, достигнут ли результат, какое действие доступно дальше или чего вы ждёте от другого человека. Выполнение одного шага не закрывает весь проект автоматически. Поддержание проектов в актуальном состоянии входит в [еженедельный обзор](13_weekly_review.md).
